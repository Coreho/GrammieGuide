## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
She is skilled, but printed patterns are small and it is easy to lose the line. Showing a saved pattern large, one page or step at a time, and remembering where she was, keeps the pattern usable without help.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The caregiver can add pattern pages from the native file picker (at least JPEG and PNG photos of pages) and give the pattern a name
- [ ] #2 She sees one page at a time, filling the screen, with large Next, Back and Home buttons
- [ ] #3 The pattern reopens on the page she last viewed
- [ ] #4 A pattern can be linked to her current project and opened from it
- [ ] #5 Pattern files are served only through the media protocol, never as file paths to the renderer
- [ ] #6 Tests cover import, paging, the remembered page and a missing file
<!-- AC:END -->
